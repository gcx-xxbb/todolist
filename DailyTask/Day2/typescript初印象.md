## 对Ts的第一印象
1. 除了常见的 静态对象 动态对象 类似 string number boolean这些之外 支持自定义接口 type等等
2. 遇到不确定的可以先用any类型 但是后期还是需要修改
3. 定义了类型之后 可以在编译阶段前 就检测到类型错误 避免了运行时错误
4. 接口和类型别名的选择：
   1. 接口：我个人理解 定义对象等等可以使用 接受泛型
   2. 类型别名：我感觉就是 定义一些具体的变量等等 可以使用 也可以和接口相合作 比如User接口 然后就可以定义publicUser = Omit<User,'password'> 类似这样的形式来自定义需要的属性
