| 类型 | 工具 | 说明 |
|------|------|------|
| 前端测试 | Jest | React 官方推荐测试框架 |

| 内存数据库 | MongoDB Memory Server | 测试用 MongoDB |

## CI/CD 集成

测试通过 GitHub Actions 自动执行：

- **触发条件**: push 或 pull_request 到 main/develop 分支
- **后端测试**: 使用 MongoDB Memory Server 进行隔离测试
- **前端测试**: 使用 MSW Mock API，无外部依赖

## 边界条件测试

### 用户模块
- 邮箱格式验证
- 密码长度验证
- 用户名唯一性
- JWT 过期处理

### 文章模块
- 文章不存在返回 404
- 未授权创建文章返回 401
- 草稿与已发布文章筛选

### 评论模块
- 评论内容长度限制
- 回复功能验证
- 级联删除

## 错误处理测试

所有 API 错误返回统一格式：

```json
{
  "status": "fail",
  "message": "错误描述"
}
```

测试验证：
- 400: 参数错误
- 401: 未授权
- 403: 权限不足
- 404: 资源不存在
- 500: 服务器错误
