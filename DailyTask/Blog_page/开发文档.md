# 博客系统前台应用开发文档

## 1. 技术选型说明

### 1.1 核心框架
- **React 18**: 采用最新稳定版本，利用并发特性提升用户体验
- **React Router 6**: 声明式路由，支持嵌套路由和懒加载

### 1.2 UI 组件库
- **Ant Design 5**: 企业级 React 组件库
  - 完善的组件生态
  - 响应式设计支持
  - 国际化支持（内置中文）

### 1.3 状态管理
- **React Context**: 用于全局状态管理
  - AuthContext: 管理用户认证状态
  - 轻量级方案，适合本应用复杂度

### 1.4 HTTP 客户端
- **Axios**: 基于 Promise 的 HTTP 客户端
  - 拦截器支持
  - 请求/响应转换
  - 错误处理

### 1.5 其他依赖
- **dayjs**: 轻量级日期处理库
- **Vite**: 现代化构建工具

## 4. 接口调用规范

### 4.1 API 服务层

```javascript
import api from './api';
import { userApi, articleApi } from './index';

// GET 请求
const data = await userApi.getMe();

// POST 请求
const data = await articleApi.createArticle({ title: '标题', content: '内容' });
```

### 4.2 请求拦截

自动在请求头添加 JWT Token:
```javascript
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

### 4.3 响应拦截

统一处理错误和响应格式:
```javascript
api.interceptors.response.use(
  (response) => {
    if (response.data.status === 'fail') {
      return Promise.reject(new Error(response.data.message));
    }
    return response.data;
  },
  (error) => {
    return Promise.reject(error);
  }
);
```

## 6. 启动和部署

### 6.1 开发环境

```bash
cd Blog_page
npm install
npm run dev
```

### 6.2 生产构建

```bash
npm run build
npm run preview
```

### 6.3 API 配置

Vite 代理配置（vite.config.js）:
```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:3000',
      changeOrigin: true
    }
  }
}
```
