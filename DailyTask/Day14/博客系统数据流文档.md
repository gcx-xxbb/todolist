## 1. 数据库设计

### 1.1 数据库概览

| 集合名称 | 用途 | 文档数量预估 |
|----------|------|--------------|
| `users` | 用户信息 | 少量 |
| `articles` | 文章内容 | 中等 |
| `comments` | 评论数据 | 大量 |
| `tags` | 标签管理 | 少量 |
| `categories` | 分类管理 | 少量 |

---

### 1.2 User Schema（用户集合）

```javascript
const userSchema = new mongoose.Schema({
  username: { type: String, required: true, unique: true },    // 用户名
  email: { type: String, required: true, unique: true },     // 邮箱
  password: { type: String, required: true, select: false },  // 密码（不返回）
  role: { type: String, enum: ['user', 'admin'], default: 'user' },  // 角色
  avatar: { type: String, default: '' },                     // 头像
  bio: { type: String, maxlength: 200 }                       // 个人简介
}, { timestamps: true });
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `_id` | ObjectId | 自动生成 | 主键 |
| `username` | String | 唯一 | 用户名，3-20字符 |
| `email` | String | 唯一 | 邮箱地址 |
| `password` | String | 不可见 | 加密存储 |
| `role` | String | 枚举 | `user`=普通用户，`admin`=管理员 |
| `avatar` | String | 可选 | 头像URL |
| `bio` | String | 可选 | 个人简介，最多200字符 |
| `createdAt` | Date | 自动 | 创建时间 |
| `updatedAt` | Date | 自动 | 更新时间 |

**设计特点：**
- `password` 使用 `select: false`，默认查询不返回
- 使用 bcrypt 加密存储密码
- 支持用户角色权限控制

### 1.3 Article Schema（文章集合）

```javascript
const articleSchema = new mongoose.Schema({
  title: { type: String, required: true },      // 标题
  slug: { type: String, unique: true },         // URL友好的标识符
  content: { type: String, required: true },    // 文章内容（Markdown）
  author: { type: ObjectId, ref: 'User', required: true },  // 作者
  coverImage: { type: String, default: '' },   // 封面图
  tags: [{ type: ObjectId, ref: 'Tag' }],       // 标签（多对多）
  category: { type: ObjectId, ref: 'Category', default: null },  // 分类
  status: { type: String, enum: ['draft', 'published'], default: 'draft' },  // 状态
  views: { type: Number, default: 0 },         // 浏览量
  likes: [{ type: ObjectId, ref: 'User' }],     // 点赞用户列表
  likeCount: { type: Number, default: 0 },     // 点赞数（冗余字段）
  favorites: [{ type: ObjectId, ref: 'User' }], // 收藏用户列表
  favoriteCount: { type: Number, default: 0 }  // 收藏数（冗余字段）
}, { timestamps: true });
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `title` | String | 必填 | 文章标题，最多200字符 |
| `slug` | String | 唯一 | 自动生成的URL标识 |
| `content` | String | 必填 | Markdown 格式内容 |
| `author` | ObjectId | 必填 | 引用 User |
| `coverImage` | String | 可选 | 封面图片URL |
| `tags` | Array[ObjectId] | 可选 | 引用 Tag（多对多） |
| `category` | ObjectId | 可选 | 引用 Category |
| `status` | String | 枚举 | `draft`=草稿，`published`=已发布 |
| `views` | Number | 默认0 | 浏览次数 |
| `likes` | Array[ObjectId] | 可选 | 点赞用户ID列表 |
| `likeCount` | Number | 默认0 | 点赞数（冗余） |
| `favorites` | Array[ObjectId] | 可选 | 收藏用户ID列表 |
| `favoriteCount` | Number | 默认0 | 收藏数（冗余） |

**索引设计：**

```javascript
articleSchema.index({ title: 'text', content: 'text' });        // 全文搜索
articleSchema.index({ author: 1, createdAt: -1 });              // 按作者+时间
articleSchema.index({ status: 1, createdAt: -1 });              // 按状态+时间
articleSchema.index({ slug: 1 }, { unique: true });             // 唯一索引
```

**设计特点：**
- 使用 `slug` 作为URL标识，利于SEO
- 使用引用（Ref）方式关联 Tag，支持多对多
- 使用冗余字段 `likeCount`、`favoriteCount` 避免每次计算

### 1.4 Comment Schema（评论集合）

```javascript
const commentSchema = new mongoose.Schema({
  content: { type: String, required: true },    // 评论内容
  article: { type: ObjectId, ref: 'Article', required: true },  // 所属文章
  author: { type: ObjectId, ref: 'User', required: true },       // 评论者
  parent: { type: ObjectId, ref: 'Comment', default: null },     // 父评论（回复）
  likes: [{ type: mongoose.Schema.Types.ObjectId, ref: 'User' }], // 点赞用户
  likeCount: { type: Number, default: 0 },      // 点赞数
  isDeleted: { type: Boolean, default: false }  // 软删除标记
}, { timestamps: true });
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `content` | String | 必填 | 评论内容，最多1000字符 |
| `article` | ObjectId | 必填 | 引用 Article |
| `author` | ObjectId | 必填 | 引用 User |
| `parent` | ObjectId | 可选 | 父评论ID，支持嵌套回复 |
| `likes` | Array[ObjectId] | 可选 | 点赞用户列表 |
| `likeCount` | Number | 默认0 | 点赞数 |
| `isDeleted` | Boolean | 默认false | 软删除标记 |

**索引设计：**

```javascript
commentSchema.index({ article: 1, createdAt: -1 });  // 按文章+时间
commentSchema.index({ author: 1, createdAt: -1 });   // 按作者+时间
```

**设计特点：**
- 使用 `parent` 字段支持嵌套回复（树形结构）
- 使用软删除 `isDeleted`，保留评论数据

### 1.5 Tag Schema（标签集合）

```javascript
const tagSchema = new mongoose.Schema({
  name: { type: String, required: true, unique: true },  // 标签名
  slug: { type: String, unique: true },                    // URL标识
  useCount: { type: Number, default: 0 }                   // 使用次数
}, { timestamps: true });
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `name` | String | 必填，唯一 | 标签名，最多30字符 |
| `slug` | String | 唯一 | 自动生成的URL标识 |
| `useCount` | Number | 默认0 | 被文章引用的次数 |

**设计特点：**
- 标签数量有限，使用唯一索引确保数据完整性
- `slug` 便于SEO和API友好

### 1.6 Category Schema（分类集合）

```javascript
const categorySchema = new mongoose.Schema({
  name: { type: String, required: true, unique: true },  // 分类名
  slug: { type: String, unique: true },                  // URL标识
  description: { type: String, maxlength: 200 },         // 描述
  parent: { type: ObjectId, ref: 'Category', default: null },  // 父分类
  order: { type: Number, default: 0 }                   // 排序
}, { timestamps: true });
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `name` | String | 必填，唯一 | 分类名，最多50字符 |
| `slug` | String | 唯一 | URL标识 |
| `description` | String | 可选 | 分类描述 |
| `parent` | ObjectId | 可选 | 父分类，支持多级分类 |
| `order` | Number | 默认0 | 排序序号 |

**设计特点：**
- 支持树形结构（通过 `parent` 实现多级分类）
- `order` 字段支持自定义排序

### 关系类型总结

| 关系 | 类型 | 说明 |
|------|------|------|
| User → Article | 1:N | 一个用户可以写多篇文章 |
| Article → Comment | 1:N | 一篇文章可以有多个评论 |
| Article → Tag | N:N | 一篇文章可以有多个标签 |
| Article → Category | N:1 | 多篇文章属于一个分类 |
| Comment → Comment | 1:N | 评论可以回复评论（嵌套） |
| Comment → User | N:1 | 每个评论属于一个用户 |
| Article → User (likes) | N:N | 文章可以被多用户点赞 |

### 4.2 文章创建流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           文章创建流程                                    │
└─────────────────────────────────────────────────────────────────────────┘

  客户端                              服务器                              数据库
    │                                   │                                   │
    │  POST /api/articles              │                                   │

    │                                   │                                   │
```

## 5. 核心查询模式

### 5.1 分页查询

```javascript
// 模式：skip + limit
const page = 1;
const limit = 10;
const skip = (page - 1) * limit;

Article.find(query)
  .sort({ createdAt: -1 })
  .skip(skip)
  .limit(limit);

// 返回格式
{
  data: {
    articles: [...],
    pagination: {
      page,
      limit,
      total,
      pages: Math.ceil(total / limit)
    }
  }
}
```

### 5.2 条件筛选

```javascript
// 构建动态查询条件
const query = {};

if (status) query.status = status;           // 状态筛选
if (category) query.category = category;       // 分类筛选
if (tag) query.tags = tag;                   // 标签筛选
if (author) query.author = author;            // 作者筛选

if (search) {
  query.$or = [                              // 搜索（模糊匹配）
    { title: { $regex: search, $options: 'i' } },
    { content: { $regex: search, $options: 'i' } }
  ];
}

Article.find(query);
```

### 5.3 关联查询（populate）

```javascript
// 单层填充
Article.find().populate('author');

// 多字段填充
Article.find().populate(['author', 'tags', 'category']);

// 指定字段
Article.find().populate({ path: 'author', select: 'username avatar' });

// 嵌套填充
Article.find().populate({
  path: 'comments',
  populate: [
    { path: 'author', select: 'username avatar' },
    { path: 'likes' }
  ]
});
```

### 5.4 数组操作

```javascript
// 添加到数组
article.likes.push(userId);
article.likeCount += 1;

// 从数组移除
article.likes = article.likes.filter(id => id.toString() !== userId.toString());
article.likeCount = Math.max(0, article.likeCount - 1);

// 检查是否存在
const isLiked = article.likes.includes(userId);

// 保存更改
await article.save();
```

### 5.5 原子更新

```javascript
// 浏览量递增（原子操作）
Article.findByIdAndUpdate(
  id,
  { $inc: { views: 1 } },
  { returnDocument: 'after' }
);

// 一次更新多个字段
Article.findByIdAndUpdate(
  id,
  {
    $inc: { likeCount: 1 },
    $push: { likes: userId }
  },
  { returnDocument: 'after' }
);
```
